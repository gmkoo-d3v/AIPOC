# 화면 캡처 출처

원본은 사용자가 제공한 작업 폴더의 `img/1/`에 있습니다. 아래 파일들은 그 이미지의 저장소 내부 공개본입니다. 원본 파일·DB 이력·계정 정보는 수정하지 않았습니다.

| 원본 | 공개본 | 가공·설명 |
|---|---|---|
| `target-optimization-main-full.png` | `target-optimizer.png` | 원본 복사. Gemini CLI가 생성·평가에 모두 선택된 설정 UI |
| `chromadb-best-practices-full.png` | `chroma-best-practices.png` | 원본 복사. 기존 테스트 문구·점수가 있는 저장·조회 시연 |
| `chromadb-rag-documents-full.png` | `chroma-rag-user.png` | 원본 복사. 일반 사용자 계정의 기존 데모 청크 조회 |
| `sqlite-explorer-full.png` | `sqlite-history-public.jpg` | 기존 파일명 열 블러 유지. 상세 JSON 파일명이 노출되는 하단은 제외하고 이력 표까지 사용 |
| `userlist.png` | `user-list.png` | 원본 복사. 관리자 사용자 목록, README의 접힌 보조 자료 |

SQLite 공개본은 원본을 로컬 HTML에서 표시한 뒤 이력 표 범위만 촬영한 평면 JPEG입니다. 미가공 원본을 숨겨 넣은 SVG 또는 메타데이터 기반 가림을 사용하지 않았습니다. 기존 `sqlite-history.jpg`는 이전 촬영본이며 README는 새 공개본을 참조합니다.

이 화면들은 설정·저장 데이터 조회 기능을 보여줍니다. 새 최적화 결과, 검색 정확도, 다운로드 성공, 권한 우회 차단 결과를 측정한 자료로 사용하지 않습니다. 원본의 시연 문구와 내부 점수를 실제 서비스 성과로 바꾸거나 재작성하지 않았습니다.
